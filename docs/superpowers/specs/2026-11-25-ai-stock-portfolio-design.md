# AI 주식 포트폴리오 설계 (토스 히트맵 + 종목 AI 분석)

작성일: 2026-11-25 · 요청: Crong

## 1. 왜 만드나

Crong님은 토스증권 계좌의 보유 종목, 현금(유동성), 주가 흐름을 **실시간으로 한눈에** 보고 싶어 해요.
그리고 종목이 왜 오르거나 내렸는지, 앞으로 어떨지 **전문 애널리스트 수준의 보고서**를 받고 싶어 해요.
목적은 **앞으로의 투자 선택에 도움을 받는 것**이에요.
AI 하나만 믿지 않도록 Claude, ChatGPT, Gemini 세 곳에 똑같이 물어봐요. 그리고 서로 맞춰 본 최종 보고서를 만들어요.

## 2. 목표 / 하지 않을 것 / 실패로 보는 것

**목표**
- 기존 히트맵(보유 종목 트리맵, 섹터 묶음, 크기=평가금액, 색=수익률, 5초 갱신, 현금, 종목 차트)을 그대로 유지해요.
- 종목을 누르면 나오는 차트 영역 아래에 **분석 버튼 두 개**를 둬요.
  - ⚡ **빠른 분석**: 세 AI가 일반 모델과 웹 검색으로 분석해요. 목표는 1~2분, 수백 원이에요.
  - 🔬 **딥 리서치**: 세 AI가 각자 가장 깊은 조사 방식으로 분석해요. 5~20분, 약 1만~2만 5천 원이 들어요. 누르면 **비용 확인창**이 한 번 떠요.
- 결과: **최종 보고서 1개, 최종 3줄 결론, AI별 3줄 요약**이 나와요.
- 보고서는 PC에 **날짜별로 저장**하고 화면에서 다시 열 수 있어요. 다시 볼 때 비용이 들지 않아요.

**하지 않을 것**
- 주문, 정정, 취소 같은 매매 기능은 넣지 않아요. 계속 조회만 해요.
- 인터넷 서버에 올리지 않아요. 내 PC(localhost)에서만 돌아요.
- AI가 "사라/팔아라"라고 단정하지 않아요. **긍정·중립·부정 시각과 이유**를 줘요.

**실패로 보는 것** (돌아가긴 해도 실패)
- 키(토스, AI)가 화면, 로그, 보고서 파일, AI 요청 중 어디에든 새어 나가는 것
- 확인 없이 비싼 딥 리서치가 실행되는 것, 또는 한 번 눌렀는데 여러 번 실행되는 것
- AI 하나가 실패했다고 전체 분석이 통째로 날아가는 것 (남은 AI 결과라도 보여줘야 해요)
- 출처 없이 그럴듯한 말만 있는 보고서

## 3. 보고서 내용

```
<종목명> 분석 보고서 (<날짜>, 빠른 분석|딥 리서치)
최종 3줄 결론
① 왜 올랐나/내렸나   (뉴스·실적·업황, 출처 링크)
② 앞으로의 전망      (좋아질 이유 / 나빠질 이유, 다가오는 일정)
③ 위험 요소
④ 세 AI의 시각       긍정·중립·부정 + 근거
⑤ AI끼리 다른 의견   (서로 말이 다른 부분 따로 표시)
내 상황에서 보면     (평균단가 대비 위치, 비중으로 인한 위험)
Claude / ChatGPT / Gemini 각 3줄 요약
```
맨 아래에는 "투자 판단의 책임은 본인에게 있어요" 같은 안내 문구를 한 줄 넣어요.

## 4. 내 정보 보내기 (Crong님 결정)

보고서를 내 상황에 맞추기 위해 세 AI 회사에 다음 정보를 보내요.
- **보내는 것**: 종목명/심볼, 시장, 현재가, 평균 매수가, 수익률(%), 오늘 등락(%), 포트폴리오 비중(%)
- **보내지 않는 것**: 이름, 계좌번호, 토스 키, 총 금액, 수량, 현금
- Gemini는 결제 등록된 키를 쓰도록 README에 안내해요. 무료 키는 학습에 쓰일 수 있어서예요.

## 5. 접근 방식

| 방법 | 장점 | 단점 | 결정 |
|---|---|---|---|
| **A. 기존 PC 프로그램에 붙이기** | 키가 PC에만 있음, 토스 허용 IP 조건 그대로 충족, 실행 방법 동일 | PC가 켜져 있어야 함 | **선택 (Crong님)** |

## 6. 정해진 것 (구조)

- 기존 구조를 유지해요: `server.js`(Node 18+, **외부 패키지 없음**), `index.html` + `d3.min.js`, `start-windows.bat`, `config.json`
- 원본 코드는 GitHub `crong930/ai` 저장소의 `toss-heatmap/` 폴더에 둬요. 완성본은 PC의 `C:\Users\munmi\Documents\toss-heatmap`에 덮어써요. 기존 `config.json`과 `.sector-cache.json`은 건드리지 않아요.
- `config.json`에 `anthropicApiKey`, `openaiApiKey`, `geminiApiKey`를 추가해요. `config.example.json`에도 자리만 넣어둬요. 키가 없는 AI는 "키 없음"으로 건너뛰어요. 세 개 다 없으면 버튼에 안내 문구를 띄워요.
- 분석은 오래 걸리니까 **작업(job) 방식**으로 해요. 버튼을 누르면 작업이 시작되고, 화면은 몇 초마다 진행 상황(AI별 대기/진행/완료/실패)을 물어봐요. 같은 종목에서 이미 돌고 있는 작업이 있으면 새로 시작하지 않아요.
- 서버는 지금 GET만 받아요. 분석 시작만 POST로 받고, `127.0.0.1`에서 온 요청이며 같은 출처(Origin)인지 확인해요. 다른 웹사이트가 몰래 비싼 분석을 시작하지 못하게 하려는 거예요.
- 흐름: 세 AI 각자 보고서 작성(동시에) → 성공한 보고서들을 **Claude가 교차 검증해 최종 보고서와 3줄 결론** 작성 → 저장
- 저장 위치: `reports/<날짜>_<심볼>_<quick|deep>.json`과 같은 내용의 `.md` 파일. 화면에 "지난 보고서" 목록을 둬요.
- 데모 모드(키 없음)에서는 가짜 보고서로 화면 흐름을 보여줘요.

## 6-1. 검토 후 정한 것 (제 결정, Crong님이 바꿀 수 있음)

- **최종 보고서 작성자**: 기본은 Claude예요. Claude 키가 없거나 실패하면 ChatGPT, 그다음 Gemini 순서로 대신 써요. 성공한 AI가 하나뿐이면 그 보고서를 바탕으로 최종본을 만들고, "교차 검증 못 함"을 표시해요. 모두 실패하면 오류와 이유를 보여줘요.
- **키 조합별 동작**: AI 호출 여부는 AI 키로만 정해요. AI 키가 하나도 없으면 가짜 보고서로 화면 흐름만 보여줘요. 토스가 데모 모드여도 AI 키가 있으면 실제 AI를 불러요. 다만 가짜 보유 정보는 보내지 않고 종목 일반 분석만 해요. 토스 설정 전에도 AI 연결을 시험해 볼 수 있게 하려는 거예요.
- **딥 리서치 비용 상한 (Crong님 결정)**: 각 AI의 검색 횟수, 출력 길이, 실행 시간에 한도를 걸어 한 번에 **최대 약 3만 원**을 넘지 않게 해요. 한도에 닿으면 보고서에 "조사 한도에 닿았음"을 표시해요. 한도는 `config.json`의 `deepResearchLimit`(또는 비슷한 이름)으로 올리거나 끌 수 있어요.
- **취소 버튼**: 진행 중인 분석은 화면에서 취소할 수 있어요. 각 AI 쪽 작업도 가능한 범위에서 취소 요청을 보내요.
- **재시작에도 이어가기**: 딥 리서치 작업 ID를 `reports/.jobs.json`에 저장해요. 프로그램을 껐다 켜도 결과를 이어서 받아요. 같은 종목이 이미 돌고 있으면 재시작 후에도 새로 시작하지 않아요. 돈을 두 번 내지 않게 하려는 거예요.
- **작업 방식**: 코드를 `crong930/ai`에 커밋하고 PR을 만들어요. 테스트가 통과한 완성본은 PC 폴더에 바로 복사해요. `config.json`, `.sector-cache.json`, `reports/`는 덮어쓰지 않아요. Mac 실행 파일은 그대로 두되, 테스트는 Windows 기준으로만 해요.

## 7. 빌더에게 맡기는 것

- 각 AI의 정확한 모델 이름과 API 호출 방식. 2026-11 기준 최신 공식 문서를 확인해서 정해요.
  - Claude: 웹 검색 도구를 쓰는 최신 모델. 딥 리서치는 검색 횟수와 생각 시간을 늘린 방식이에요. Anthropic API에는 별도 "딥 리서치 모델"이 없어서 가장 가까운 방식을 써요.
  - ChatGPT: OpenAI의 딥 리서치 모델이 있으면 백그라운드 모드로, 없으면 웹 검색과 긴 추론 방식으로 대신해요.
  - Gemini: 공식 Deep Research 에이전트를 써요. 빠른 분석은 Google 검색 그라운딩을 써요.
- 각 AI 응답에서 출처 링크를 뽑는 방법, 시간 제한, 재시도 횟수
- 화면 세부 디자인. 기존 화면 스타일을 따라요.
- 비용 안내 숫자. 대략적인 범위만 보여줘요.
